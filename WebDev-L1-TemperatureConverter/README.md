# Temperature Converter Website

A simple and responsive temperature converter built using HTML, CSS and JavaScript.

## About the Project

This project converts temperature values between Celsius, Fahrenheit and Kelvin.

The application validates user input and displays a clear error message for invalid values and temperatures below absolute zero.

## Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Numeric input validation
- Absolute zero validation
- Clear error messages
- Responsive design
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Conversion Formulas

Celsius to Fahrenheit:

F = (C × 9/5) + 32

Fahrenheit to Celsius:

C = (F - 32) × 5/9

Celsius to Kelvin:

K = C + 273.15

Kelvin to Celsius:

C = K - 273.15
