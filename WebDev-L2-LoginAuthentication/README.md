# Login Authentication System

## Project Overview

The Login Authentication System is a client-side authentication web application developed using HTML, CSS, and JavaScript.

The application provides user registration, password validation, secure password hashing, login authentication, session management, and access to a protected dashboard.

## Features

- User registration using username/email and password
- Password validation with minimum 8 characters
- Password must contain at least 1 number
- Duplicate username/email checking
- User login authentication
- Incorrect credential error handling
- Protected dashboard page
- Session-based access control using localStorage
- Logout functionality
- SHA-256 password hashing
- Basic form validation
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- Web Crypto API
- SHA-256 Hashing
