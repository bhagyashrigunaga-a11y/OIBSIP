# Personal Portfolio Website

## About the Project

This project is a responsive personal portfolio website created as part of the Oasis Infobyte Web Development & Designing Internship.

The portfolio presents my profile, technical skills, projects, and contact information in a clean and responsive layout.

## Features

- Responsive navigation bar
- Hero section with profile introduction
- About Me section
- Technical Skills section
- Projects section
- Contact section
- Smooth scrolling navigation
- Responsive design for desktop, tablet, and mobile
- Consistent typography and colour scheme

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
