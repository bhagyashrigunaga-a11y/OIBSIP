# Calculator

## Project Overview

The Calculator is a responsive web-based calculator developed using HTML, CSS, and JavaScript.

It performs basic arithmetic operations with a clean and user-friendly interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Decimal number support
- Clear button
- Backspace button
- Sequential calculations
- Division by zero error handling
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
